# Como o João usa o Praxis

Atualizado: 2026-07-08 (simplificação menu 5 + Hoje enxuto)

## URL certa

- **App:** https://dopraxis.vercel.app  
- Se a tela parecer velha: **Ctrl+F5** (ou limpar cache do navegador).

## Os 3 comandos do dia

1. **Hoje** — o que fazer agora + tarefas/hábitos do dia  
2. **Falar** (botão do meio no celular) — grava áudio, a IA organiza na fila  
3. **Tarefas** — lista completa, atrasadas, editar

**Revisar** = revisão semanal. **Mais** = ideias, foco, compras, histórico, config.

## Se “sumiu” algo

1. Confirma que está em **dopraxis.vercel.app** (não outro alias antigo).  
2. **Ctrl+F5**  
3. Se a API falhar: login de novo; em último caso avisa a A.N.A. com print.

## Onde ficaram gráficos e posts

**Histórico** (menu **Mais** → Histórico): heatmap, correlações, posts Instagram planejados.

## Deploy (só referência)

- Front: push `main` → `npm run deploy:prod`  
- API (só se mexeu em `api/`): `npm run ship:api` na VPS

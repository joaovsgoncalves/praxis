# Lista limpa — arquivar vs concluir

**Concluir** — você fez (ou não precisa mais fazer) e quer crédito no dia / histórico.

**Arquivar** — sumir da lista ativa sem fingir que fez: ruído, ideia velha, tarefa atrasada que não vai rolar. Vira `cancelled` na API (não apaga o registro).

**Atalhos:** chip **Atrasadas** → **Selecionar** → **Arquivar**. Banner no **Hoje** leva direto pra esse filtro.
